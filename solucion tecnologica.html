Solución tecnológica

En esta sección se presenta nuestra solución tecnológica, explicando su funcionamiento, características y la manera en que ayuda a solucionar la problemática identificada. Es un dispositivo diseñado para medir constantemente la temperatura del aula y avisar al docente cuando esta comienza a aumentar demasiado. Cuando se alcanza una temperatura establecida, el dispositivo emite una alerta para que el docente pueda considerar salir del salón y realizar una actividad al aire libre.

¿Cómo funciona?

1. Un sensor de temperatura mide constantemente la temperatura del aula.

2. El dispositivo analiza los cambios de temperatura.

3. El docente recibe la alerta y puede decidir realizar una actividad fuera del aula.

4. Los estudiantes realizan una actividad en un espacio exterior más ventilado.

5. El dispositivo continúa midiendo la temperatura para comprobar si las condiciones del aula mejoran.

Características

  • Fácil de utilizar.
  • Accesible para los usuarios.
  • Bajo consumo de energía.
  • Funcionamiento automático y continuo.
  • Permite establecer un límite de temperatura según las condiciones del proyecto
